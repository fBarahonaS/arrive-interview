# Arrive Mini-App

A lightweight ReactJS & TypeScript mini-app designed for requesting a list of products and filter over them.

## Tech Stack
* **Framework:** React JS (TypeScript)

## Getting Started
### Prerequisites
* Node.js (>= 18)
* NPM

### Setup & Run
```bash
# Clone and install dependencies
git clone https://github.com/fBarahonaS/arrive-interview.git
cd arrive-interview
npm install

# Start ReactJS App
npm run start
```
